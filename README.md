# Multimodal LLMs- CLIP & BLIP-2

Exploring cross-modal alignment and visual 
question answering with CLIP and BLIP-2.

## What's here

### CLIP (OpenAI)
- Text and image embeddings
- Cosine similarity matrix across images and captions
- Cross-modal alignment visualisation
- SBERT version of CLIP

### BLIP-2 (Salesforce)
- Image captioning
- Visual Question Answering (VQA)
- Multi-turn chat-like VQA with memory

## Tech Stack
CLIP · BLIP-2 · HuggingFace Transformers · 
SBERT · PyTorch · Cross-modal Alignment · 
Vector Embeddings · Multimodal LLMs
